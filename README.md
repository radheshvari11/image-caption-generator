# Image Caption Generator

A deep learning project that generates natural language captions for images using CNN and LSTM architectures.

## Technologies Used
- Python
- TensorFlow
- Keras
- Deep Learning
- NLP
- CNN (VGG16)
- LSTM

## Features
- Image feature extraction using VGG16
- Automatic image caption generation
- NLP preprocessing and tokenization
- Sequence prediction using LSTM
- Deep learning training workflow

## Dataset
- Flickr8k Dataset

## Future Improvements
- Attention mechanism
- Transformer-based captioning
- Real-time image caption generation
